## 二、html/ 审阅页面

三个文件都是**单文件自包含**：截图全内联 base64，无外部 JS/CSS，无联网请求，断网也能看。

| 文件 | 大小 | 节点 | 截图 | 说明 |
|---|---|---|---|---|
| `设计审阅.v0.2.0.html` | 22.98 MB | 154 | 146 | **现行版**，第 1–8 章全量 |
| `设计审阅.html` | 4.38 MB | — | — | v0.1.0 工作版，仅第 1–7 章 |
| `设计审阅.v0.1.0.html` | 4.38 MB | — | — | v0.1.0 冻结存档，不要改 |

### 页面结构

```
┌──────────┬───────────────────────┬──────────────────┐
│ PRD 章节  │      原型截图          │  该节点的 PRD 正文 │
│ 1~8 章    │   （只放截图，可放大）   │   （完整原文）     │
└──────────┴───────────────────────┴──────────────────┘
```

### 怎么用

1. **左栏**点章节（1–7 章是文档，第 8 章是功能描述树）
2. 第 8 章里**点任意一个节点** → 中间出该节点截图，右侧出该节点 PRD 正文
3. 点截图可**放大**（滚轮缩放、拖动、← → 切图、Esc 关闭）
4. 左上角「← 返回列表」回到第 8 章目录树

### 两个辅助阅读的小功能

| 功能 | 表现 | 说明 |
|---|---|---|
| **返回原位** | 从详情页点「← 返回列表」，目录树回到你点进去时的滚动位置 | 不做自动居中，避免阅读位置被重置 |
| **上次打开标记** | 你最近一次点进去的那一行变成**琥珀色**（浅黄底 + 左侧竖条 + 加粗） | 全树**只保留一行**，点开的其他节点不留痕；刷新页面后仍在 |

标记只保留一项，是为了让开发一眼看到"我上次看到哪了"，又不会被一堆颜色干扰。

### 第 8 章覆盖范围

```
8.1 APP 端功能描述     8.1.1 首页 -- 非处理人（13 节）｜8.1.2 处理人端（3 节）
8.2 WEB 端功能描述     8.2.1 聊天控制台 ｜8.2.2 分流配置 ｜8.2.3 群聊管理
                      8.2.4 配置模板 ｜8.2.5 敏感词管理 ｜8.2.6 消息推送
8.3 POS 端功能描述     8.3.1 单店铺群 ｜8.3.2 多店铺群
```

## 三、docs/ 文档

| 文件 | 作用 | 什么时候读 |
|---|---|---|
| `上下文交接.md` | **总纲**：内容铁律、构建链、解析器结构、校验体系、20 条踩坑、未完成项 | 接手第一件事 |
| `进度记录.md` | 进度表：逐条需求「用户原话 → 落点」对照、校验结果 | 想知道某条改动在哪 |
| `会话记录.md` | 历史：时间线、用户原话锚点、方案演进过程 | 想知道为什么这么做 |

三份文档的分工：**交接**是总纲，**进度**是清单，**会话**是历史。

## 四、内容来源与原则

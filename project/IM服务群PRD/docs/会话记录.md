## 五、技术上确认下来的事实

### 5.1 语雀 API

- `doc.mjs --out` 时 exit=0；只打正文时 exit=1 但内容正常（`# source: cache...` 写进 stderr）
- token 存在 `skills/yuque-docs/yuque/state.json`，被 gitignore
- 缓存 30 分钟

### 5.2 墨刀

- 端点 `https://modao.cc/agent-py/ai/mcp` 只认 OAuth 2.1+PKCE，**不能用 API token**
- 授权窗口 3090 端口，`login.mjs` 只等 10 分钟
- token TTL 3600 秒，存在 `skills/modao-prototype/modao/state.json`，被 gitignore

### 5.3 PowerShell 坑

- `[System.IO.File]::ReadAllBytes('相对名')` **不跟 `cd`**，必须绝对路径
- `git commit -m "带引号的内容"` 会被当语法解析 → 用 `git commit -F <临时文件>`
- `node -e "..."` 里的 `$` 会被 PowerShell 吃掉 → 写 `.js` 文件再跑
- 把 `node -e` 的输出传给 `Select-Object` 时，管道元素不能跟在 `}` 后面

### 5.4 模板的交互语义

- `data-*` 是 HTML 自定义数据属性，语义完全由 JS 赋予
- 第 52 行点击代理：`const nav = event.target.closest('[data-page],[data-go]'); if(nav) render(nav.dataset.page || nav.dataset.go);`
- `render()` 里先重置所有 `aria-current`，所以 tab 高亮永远跟随 `page` 变量，不会错位
- **`data-page`（左栏 tab）和 `data-go`（画布按钮）职责不同，都要保留**

| 8 | 删掉 seen 整套逻辑，只留 last | 「有这个痕迹就可以了」 | 用户要的是「我上次看到哪」，不是「访问历史」 |

**核心教训：改样式前必须先打印真实 DOM 结构。前 5 轮在配色、特异性、时序上全部白转。**

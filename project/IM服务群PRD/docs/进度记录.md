## 五、踩过的坑（下次别再踩）

1. **正则回溯**：`/^(?:\*\*)?([^*#|>][^:：]{1,12})(?:\*\*)?[：:]\s*$/` 在大文档上直接把 Node 挂死。大 Markdown 用 `indexOf` / `startsWith` 逐行扫。
2. **`Set-Content -Encoding UTF8` 毁中文**：写含中文的文件用 `write` / `edit` 工具，不要走 PowerShell 管道。
3. **`node -e "...$..."`**：PowerShell 会吞 `$`，写成 `.js` 文件再跑。
4. **`Get-Content -Raw` + `.Replace()` + `Set-Content`** 同样毁中文。
5. **核对内容时必须还原冒号**：`<b class="k">键</b><span class="v">值` 要拼回 `键：值` 再比对，否则误报 78% 缺失。
6. **移除文案别用全文 `replace` 兜底**：`/\s*待审阅\s*/g` 会误伤大图查看器的 script，导致 `Unexpected token '<'`。

## 真正的根因：选择器选错了层（关键教训）

高亮逻辑前 6 轮"改配色、加特异性、调时序"全部无效，真实原因是**选择的 DOM 层级不对**：

```html
<div class="ch8row d0 haskids" style="padding-left:10px">   ← 外层行，没有 data-go
  <button class="ch8go" data-go="0"> ... </button>           ← data-go 在内层按钮上
</div>
```

代码写的是 `document.querySelector('.ch8row[data-go="122"]')` —— 这个选择器**永远返回 null**，所以 `row.classList.add('last')` 一次都没执行过。

修法（`_tmp_build_ch8.js` 三处统一）：
```js
function rowOf(k){
  if(k==null) return null;
  try{ return document.querySelector('.ch8row .ch8go[data-go="'+k+'"]'); }catch(_e){ return null; }
}
var lastBtn = rowOf(from);
var row = lastBtn ? (lastBtn.parentNode || lastBtn) : null;
```
记录分支与 `markNav` 捕获监听同样改成后代选择器 + 取 `parentNode`。

**这一轮浪费 6 轮以上的教训**：改样式前必须先 `console` 打印真实 DOM 结构（`_tmp_dbg_treestruct.js` 一跑就暴露了），不要照假设改选择器。

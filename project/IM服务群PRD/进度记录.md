## 五、踩过的坑（下次别再踩）

1. **正则回溯**：`/^(?:\*\*)?([^*#|>][^:：]{1,12})(?:\*\*)?[：:]\s*$/` 在大文档上直接把 Node 挂死。大 Markdown 用 `indexOf` / `startsWith` 逐行扫。
2. **`Set-Content -Encoding UTF8` 毁中文**：写含中文的文件用 `write` / `edit` 工具，不要走 PowerShell 管道。
3. **`node -e "...$..."`**：PowerShell 会吞 `$`，写成 `.js` 文件再跑。
4. **`Get-Content -Raw` + `.Replace()` + `Set-Content`** 同样毁中文。
5. **核对内容时必须还原冒号**：`<b class="k">键</b><span class="v">值` 要拼回 `键：值` 再比对，否则误报 78% 缺失。
6. **移除文案别用全文 `replace` 兜底**：`/\s*待审阅\s*/g` 会误伤大图查看器的 script，导致 `Unexpected token '<'`。
